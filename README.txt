YESHUA KOFI DEI — PERSONAL PORTFOLIO

Built with React, Vite, Tailwind CSS and Framer Motion.

Run locally:
1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev` and open the local URL shown in the terminal.

Production build:
1. Run `npm run build`.
2. Deploy the generated `dist` folder to a static host such as Vercel.

Project files:
- `src/App.jsx`: page sections, reusable components and contact form behavior
- `src/index.css`: responsive layout and visual system
- `index.html`: metadata and application entry point
- `public/yeshua-kofi-dei-cv.txt`: downloadable CV
- `public/assets/portrait.jpg`: portrait
- `public/assets/campusnest-login.png`: CampusNest project image
- `public/assets/quiet-video.mp4`: creative video sample

The contact form prepares an email in the visitor's default mail app; it does
not send or store form data. Social profile links are included in the contact
section and footer.
